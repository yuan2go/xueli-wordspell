# 01 · 产品与范围

当前产品名：雪梨英语奇旅 / Xueli English Quest；仓库 `yuan2go/xueli-english-quest`。首个故事《小猫的野餐冒险》。当前工作包 WP-GAMEPLAY-CORE-04，覆盖并替代旧包中固定步骤和通关后才探索的限制。

## 核心体验

发现问题 → 理解所需语言 → 选择或尝试办法 → 操作世界 → 看见后果 → 调整或进入新情境。场景是主要入口；拼写和组句工具按对象/行动展开。面向有基础拼读经验的玩家，难度按实际语言基础安排，不用年龄推断能力。

当前故事使用家门口、湿墨小径、野餐草地，核心词 cat/bag/map/mat/hat/cap，位置关系 in/on。三幕、六词是本故事的有限内容范围；三字母、十二挑战和十三步骤不作为全局限制。没有为未来内容建设通用编辑器。

## 已授权交付范围

- 主线按世界条件与已提交行为事实推进；必要教学保序，准备物品与布置可合理换序。
- 恢复同伴后开放真实探索：开合包、取出/收纳、佩戴/换帽/摘帽、摆放和纸张可逆变形。
- 语言意义先于尝试；拼写检查仍判断本题声音，探索有效词按制作配额产生物品，不把一切词变成错误投影。
- 基础选词组句：指令句执行动作；描述句核对观察；语言结构、场景含义、世界许可和目标完成分别反馈。
- 三个相关短活动，每个两个人工变体；按所需能力提前开放、固定变体恢复、退出/重玩不污染主线。
- 真实布置驱动结局和回顾；记录教学/辅助/独立/探索/回访，支持保守存档恢复。

## 非目标与证据边界

不做账号、支付、社交、成长系统、开放聊天、麦克风评分、无限物品、万能编辑器、后台或实时 AI。Provider/AI 工坊维持暂停。开发工具使用 AI 与游戏运行时模型分开。

目标儿童试玩、真机、正式录音、教研和素材授权仍是独立验收，不能从自动化通过推定。产品好玩、词汇掌握或学习提升都需要相应观察/研究；本包只报告真实实现与工程验收。

原活动背景、时间安排和外部产品参考是负责人提供的历史背景，不是本仓库已获得的公司授权或教学效果证据；来源见 10。公开发布需要资源/内容审核和部署验收，不能把仓库链接当成游戏链接。
