# 02 · 场景目标、玩法与内容

## 三幕与自主决定

| 场景 | 问题与必要教学 | 当前完成条件与自由选择 |
| --- | --- | --- |
| 家门口 | 用图、短句和词音恢复 cat；bag 表达装东西的用途 | 同伴出现后可先找背包或地图；背包带来独立纸偶，帽子可提前恢复、试戴，开合包/收纳/取出即时可用。存在旅行背包及 map 形态的 route-sheet 后主动出发 |
| 湿墨小径 | 猫在近岸受阻，点纸学习 map→mat；先看用途再换尾字母 | 只有 route-sheet(mat) 可铺路并提交 crossed-ink，猫移动到对岸。收回同一纸张后 mat→map 才能导航去草地；没铺路不能恢复地图 |
| 野餐草地 | 制作独立 picnic-mat；用 Put…in… 学行动，The…is on… 学观察 | 收 cap 的句子与摆 hat/描述可按不同顺序；完成两类教学后邀请猫、听音找路线。任选 hat/cap 戴着，另一顶可收包或留垫上；稍后用描述句回顾该选择，当前布置进入结局 |

物品实例：cat-companion 永远为主角；cat-card 为可逆 cat↔cap 纸偶；route-sheet 为可逆 map↔mat；picnic-mat 独立；bag-main 和 hat-main 唯一。恢复和制作含义区分：拼 cat/bag/map/hat 恢复有限关键实例；拼 mat 制作新野餐垫；自由制作规则只允许 craft-mat/craft-hat 各一件。主角、纸偶、背包、路线不得通过制作复制。

目标函数读取当前世界与真实事实，不由 UI 自行打勾。完成过教学是历史事实；佩戴、座位和收纳等布置目标还须当前世界满足。结局完成后仍可调整，显示当前真实布局，不虚构能力奖励。

## 操作和可逆退路

点击物品展开行动，点合法地点或拖过去；键盘 Tab/Enter 等价。未选中不强提示所有目标。按当前物品和世界规则生成目标；落空/取消保持原位，不加入语言错误。

背包先打开才能取里面物品，关闭隐藏内容但保留实例；“放回地面”可取出、摘帽、移开占用。换帽会原子地把旧帽放回地面。含物品的支撑物不能变形或整体收进其他物体，容器和支撑关系无环。包内或戴着的变形物须先取出/摘下；地图纸必须实际完成过路条件。

有限的图像与文字提示先表达意义。听音拼写的完整目标词默认隐藏，文字/提示/示范显式记录；不完整输入、资源失败、重听和操作失败不是语言错误。自由探索按内容规则生效，不计练习分数。

## 句子内容与判定

`content/sentences.ts` 为每项声明语言目标、情境、词块独立 ID、接受的模板、语义 source/relation/target、稳定实例映射和 place/observe 用途。

- 指令：`Put the cap in the bag.`；也接受 `In the bag, put the cap.`。语义与情境符合且世界许可才执行。
- 描述：`The hat is on the mat.`；也接受 `On the mat is the hat.`。只核对可见世界，不执行搬动。
- 两块 the 有不同 ID，支持撤回和左右重排；标点可选，大小写规范化。
- 少词反馈 incomplete；已收录结构需调整反馈 structure；其他可能成立表达反馈 outside；语句成立但非目标/非眼前位置反馈 mismatch；世界条件阻挡反馈 blocked，保留语言正确。
- 成功后原子提交句子事实与世界动作，目标再投影。一次组句不代表语法掌握。

顺序：教学 pack-cap 与辅助 describe-hat → 独立 invite-cat → 听音寻找 → 依据玩家自己布置的 recap 回访。短活动再次运用相关句型，不把重复通关当主线成绩。

## 三个短活动：每种两个人工情境

| 活动与解锁 | 变体 0 | 变体 1 |
| --- | --- | --- |
| 帽子搭配：已有 hat 且做过纸偶变帽 | 纸偶变帽，任选一顶戴上，另一顶收包、合包 | 小猫开始戴着宽帽，纸偶在包内；取出变贴头帽，替换佩戴，宽帽留在垫上 |
| 背包找物：完成 in 指令和 on 描述教学 | 一帽在外一帽在包内；开包观察，描述藏着的帽子，再放到垫上 | 包压在垫子上遮挡鸭舌帽，另有帽在包内；挪开遮挡，观察描述露出的 cap，再收包 |
| 野餐小帮手：成功用句子邀请猫 | 路线纸变新座位，用句子请猫坐上去；收 cap 的句子可先后任意 | 路线纸已为 mat 且帽子压着；先移走并戴好 hat，再恢复地图；用句子收 cap，顺序可调整 |

活动世界与主线隔离；只按所需能力解锁，不拿预置通关世界冒充主线。活动初始布局是明确手工关卡。每局 seed、variant 和日志持久化；刷新不变，重玩 seed+1 切换另一种关系/解法。退出恢复原主线布置，活动再次进入可继续。所有六个变体有实际规则路径与 HTTP 操作验证；不宣称穷举任意操作序列。
