# 03 · 交互、美术和音频规格

## 当前场景入口 · WP-GAMEPLAY-CORE-04

正式 App 使用 Scene/Letters/SentenceBuilder，场景对象先于练习工具；不再常驻关卡编号或固定题目面板。桌面/Pad 左场景右工具；手机竖屏以固定可视场景和有界工具区共同使用，词块与主要提交按钮可在合理视口操作。字母 48px、主要动作 44px，辅助小按钮保留清晰焦点；360×640 为实际回归视口，不宣称真机触控验收。

包内、垫上和佩戴物从 location 递归挂在所属对象的局部布局中，避免按屏幕百分比让帽子浮空。未选中不标亮所有答案目标；拖动显示物品图像，合法目标来自同一世界许可试算，提交后吸附到稳定位置，落空和 pointer cancel 留在原位。新一次物理按压不被前一次拖动的合成点击抑制吞掉。

点击伙伴/问题/道具都会有短回应。狸花猫不镜像，佩戴位置避开画面颈部右侧白色定位器；静态/思考/行动/抵达表现依据实际情境和提交结果。动画有界并支持 reduced-motion，暂停/后台/刷新直接保留已提交结果。

字母与词块用清晰系统 sans-serif；句型首次示范、辅助和回访明确标记。新增描述句语音目录是未审核浏览器开发 TTS，沿用单一可取消 StoryAudio，不新增音效盖住教学语音。当前测试和截图见 STATUS；以下美术来源与通用约束继续有效，旧线性页面描述仅为历史。

## 当前工程接入（2026-09-19）

WP-TABBY-ART-UI-CUTOVER-01 在正式 `index.html → src/main.tsx → App` 接入纸上小径绘本页面。`src/ui/tokens.css` 是唯一配色入口：暖纸 #f5efdf、墨绿 #254b3d、赭黄 #c89845；标题用系统宋体/serif，小写字母用 Arial。桌面场景与任务双栏，平板调整比例，手机紧凑场景后接任务和字母盘，保留滚动；字母至少 56px、其他主要控件至少 44px。首页、教学、主线、暂停、结局、记录及既有野餐均使用同一资源链。

`src/content/manifest.ts` 导出 `visual-assets.ts` 中唯一图片登记。`Scene → Art/CharacterArt/Visual → assetPathById → IMAGES` 指向 `public/assets/game/tabby/`，使用 Vite BASE_URL。三张独立背景不含可移动物品；棕灰虎斑猫保留画面颈部右侧白色定位器、灰项圈、绿围巾与背包，不水平镜像。待机、思考、行动三个原生 PNG 与五件道具各自独立；结局复用用户确认的 512px 欢呼图（显示不超过 220 CSS px，不宣称存在高清 master）。纸偶以纸托区分，领域实例仍独立。

原始 master、四张页面参考及实际生成记录见 [美术目录](../design/tabby/README.md)。页面参考只指导构图，不作为整页背景。旧临时 SVG、损坏/未使用 WebP、程序化场景和第二份资源清单已移除。启动预检和晚到的图片错误均显示文字轮廓与重试；重试保持当前输入和已提交进度，不回退旧角色。

同一 manifest 登记六词及四句语音，路径为 null、review=PENDING；StoryAudio 沿用 en-US 浏览器完整词/句 TTS 开发替代。取消、重播、音量、静音、后台停止与失败辅助均保留；录音、口音和教学质量仍需审核。视觉接入与素材权利、音频、教研、公开发布资格分别记录，发布校验未放宽。

## 1. 页面与导航

首版页面：启动/资源检查 → 开场 → 故事场景 → 暂停设置 → 结局/绘本回顾 → 本地练习详情。工坊独立成人入口；隐藏按钮不是鉴权。资源预检有明确加载状态，未实现按钮不能假装已完成功能。

首页一项主操作“开始冒险”，有继续存档时增加“继续”和带确认的“重新开始”。不要求注册。暂停可调音量、重听当前任务、返回首页和清除记录；重新开始不能静默覆盖旧记录。

手机竖屏：顶部进度和暂停；中上部场景；中下部当前任务与重听/帮助；底部字母盘或选物操作。Pad 横屏增加场景空间，任务盘可在右侧，不简单拉伸手机截图。参考测试尺寸 360×640、390×844、768×1024、1024×768；这些是测试基准，不是对所有设备的保证。

## 2. 输入协议

字母点击→首个空槽；槽内点击→退回盘；拖到已有槽→交换。变形题固定未变化位，但不能在独立拼写题中偷偷锁定答案。施法按钮仅在输入结构完整时可用。用稳定字母 tokenId 区分相同字母，避免复制或丢字。

使用 Pointer Events，设置合理的 touch-action；在拖放元素上处理 pointercancel、指针捕获、手指离屏、屏幕旋转。不要给整个页面设 touch-action:none 而阻断必要滚动。不依赖原生桌面 HTML drag-and-drop，也不把 hover 当提示入口。[输入资料见来源文档]

点击物品后视觉选中；点击目标提交与拖放相同的领域命令。拖动容忍适度位移，落空复位；多指只接受当前 active pointer。动画与请求在处理中时阻止重复提交，但暂停/恢复不能永久锁死。

字母按钮建议最小约 56×56 CSS px，其他核心按钮至少约 48×48；在 360 宽度下采用受控列数/换行，不能为凑一排缩到无法触摸。无障碍目标需结合实际布局验证，不宣称仅凭尺寸符合全部标准。

## 3. 视觉语言与动效

纸张层次、温和背景、明显的字母对比；少量角色动作表现因果。场景按真实物品变化、铺路、过路及书页修复记录表达进展。字母使用清楚的小写形态，不旋转、不使用导致 a/g 难辨认的装饰字体。系统字体优先，不依赖第三方字体 CDN。

动作建议：选择反馈 100–180ms；施法/变形 450–800ms；错误反馈约 1 秒，重复时缩短。数值为设计预算，真机可调。prefers-reduced-motion 下直接显示已提交结果；不得靠 animationend 唯一推进业务。逻辑成功后刷新/跳过动画仍应保留结果。

错误投影是短期表现层对象，不写入正式 inventory。正式地图和垫子要有明显形态区别。主人公和 cat-card 的视觉尺寸/位置也必须不同，防止孩子以为同伴被变没。

## 4. 音频资源与播放服务

六个完整词音频；三个句子至少覆盖 Put the cap in the bag / Put the hat on the mat / Put the cat on the mat；Find the map；必要旁白与纠错。精确资产清单在内容包 manifest，资源全部是已审核草稿或正式产物，状态不可混用。

完整单词与音素素材分开。字母名称不是音素读音；不得将通用 TTS 对单字母的朗读用作拼读音。确定一种发音标准并让教研审核，不在一关中混用不同目标口音。

浏览器的首次点击应激活音频；Autoplay/AudioContext 失败要可观察。AudioService 统一控制：播放新任务取消旧任务语音；重听不会层层叠加；语音优先于环境音；离开页面或后台暂停，恢复时提供重听。绝不依赖背景音乐作为答题提示。

每页进入前预加载必需词音，其他按页懒加载；播放失败可重试。用户选择文字辅助后记录 inputMode=text-assisted；不能显示完整答案仍记纯听力完成。无需强制麦克风或 SpeechRecognition；浏览器语音合成仅可用作标注清楚的开发替代，不是正式教学语音。

## 5. 素材制作与权利记录

首版需要 3 张背景、1 个小猫角色及少量表情、6 类物品/纸偶、施法与修复状态、UI 控件。优先原创或公司授权素材。AI 图片需检查字母、手部、角色一致性，图片内不让模型生成需要准确识别的题目文字；字母由 DOM 渲染。

manifest 记录 assetId、路径、类型、word/scene 关联、审核状态、生成工具/作者、来源和授权备注；未确认许可的资源不进入公开构建。仅在确需时保存实际生成提示词，不能夹带公司内部资料或儿童照片。

## 6. 无障碍与故障交互

清晰焦点、语义按钮、键盘等价输入、不能只用颜色表示正确错误、尊重 reduced-motion。aria-live 播报简短结果，不在每次拖动时长篇打断。屏幕阅读辅助公开答案时如实标记辅助模式。

资源错误显示重试/返回；无存储权限仍可临时游玩，提示“本次进度可能不保留”；旧版本存档提供恢复或重开，不自动清空；旋转后重算布局并取消未完成拖动。页面最低可用性优先于装饰粒子和大幅动效。
