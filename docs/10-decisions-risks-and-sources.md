# 10 · 设计决策、风险、来源和假设

## 当前有效决策 · 2026-09-20 / WP-GAMEPLAY-CORE-04

| 决策 | 当前结论 |
| --- | --- |
| 产品与主线 | 雪梨英语奇旅 / Xueli English Quest；按世界目标与行为事实推进，旧 step++ 不驱动正式页面 |
| 范围数量 | 三幕六词是首个故事的编排，不把三字母、十二挑战、十三步骤固化成产品限制 |
| 早期探索 | 恢复同伴后，按实际出现物品开放可逆玩法；主线自由布置不借用通关初始状态 |
| 英语应用 | 有限语法/语义判定；命令执行，描述核对。目标不符与世界受阻不等于错误英语 |
| 制作与身份 | restore/make/transform/find 明确区分；craft-mat/craft-hat 各一件，关键物品不复制 |
| 目标与结局 | 准备/布置允许合理换序；帽子与收纳选择保留到结局，当前布置来自真实世界 |
| 活动与随机 | 复用三活动，每个两个实质变体；能力解锁，隔离世界，固定 seed/variant 恢复 |
| 状态和存档 | 同一 domain.transition，schema 4 重放并核对投影；旧 step 无法可靠迁移新目标，备份/导出后明确重开 |
| 证据 | 教学、辅助、独立、探索、回访分开；TTS 明示未审核，自动化不证明好玩、教研合格或学习提升 |

以下为历史决策，若与上表冲突以当前规则及 01/02/04/05 为准。

## 1. 对此前对话的合并与修正

| 决策 | 当前有效结论 | 原因 |
| --- | --- | --- |
| 名称 | xueli-wordspell / 雪梨单词魔法师 / 小猫的野餐冒险 | 不绑定单一课件，保留 WordSpell 的拼写与魔法含义 |
| 玩法核心 | 拼词造物、换字变物、听音互动 | 英语改变场景用途，不只是答题奖励动画 |
| 数量口径 | 3 幕、12 挑战、13 底层步骤 | 第 04 关包含变形与铺路，不把铺路跳过 |
| 物品身份 | map↔mat 同一个 route-sheet | 真实变形，而非地图和垫子同时复制 |
| 小猫保护 | cat-companion 不变；cat-card→cap | 避免主角消失或状态死局 |
| 帽子语义 | 明确点名目标；不做 hat/cap 排他图像题 | cap 与更宽泛帽子概念不应硬判互斥 |
| 第八关 | 新建 picnic-mat | 与已经恢复 map 的 route-sheet 区分 |
| 错词表现 | 投影不进入权威世界 | 保留趣味，同时不创造无限道具 |
| 学习证据 | 按题型、帮助、答案可见性分别记录 | 不把提示完成、换字和独立拼写混在一起 |
| AI 地位 | 主线预生成审核；工坊 P1 | 在线依赖不能拖垮一周作品 |
| 技术选择 | 轻量 React/TS/Vite＋确定性领域内核 | 不是平台、通用图形引擎或大型多模型路由 |
| 文档状态 | 设计不等于实现，STATUS 单独维护 | 避免后续 agent 用规格/Mock 宣称端到端 PASS |

这些是本次对话方案的整理，不冒充公司内部已批准教研标准。

## 2. 风险与应对

| 风险 | 触发/识别 | 应对 |
| --- | --- | --- |
| 核心不好玩 | 只会机械填字，看不懂变形用途 | 先做 WP-01 真正过路切片，再扩关卡 |
| 教学混淆 | 字母名当音素、帽子排他、泄露答案 | 教研审查、模式标记、独立测试 |
| 状态死局 | 变走正在用的垫子、缺地图、主角变帽子 | 实例/步骤守卫、恢复测试、同内核可达性检查 |
| 工期不足 | 工坊、美术或平台功能占用关键路径 | 保 P0，降级 P1/P2，说明真实范围 |
| 网络或音频 | 移动端无法访问、播放被阻止 | 本地资源、首次交互解锁、真实网络验收 |
| API 成本失控 | 公共端点无权限/并发限额 | 默认关闭、授权预算、服务端原子限制 |
| 权利与隐私 | 直接取公司课件/真人声线/儿童数据 | 原创占位、授权后替换、无个人数据默认 |
| 双 agent 覆盖 | 同工作区修改核心协议与 lock | 一包一负责人、独立 worktree、先合约后并行 |
| 环境验证缺口 | npm 安装不可用、只有逻辑测试 | 如实标 BLOCKED，联网后生成锁并构建，不伪造 |
